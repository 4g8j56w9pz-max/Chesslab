Credits

Engine: Dwasm, based on PrBoom+/PrBoomX, built from pinned source included in this repository.

Game content: Freedoom Phase 1 v0.13.0, included as freely redistributable content.

Project artwork: The status-bar portrait is a NIGHTFALL-local pixel-art patch generated from a user-provided reference image and loaded separately from Freedoom.

Runtime: Emscripten WebAssembly output, software renderer, single-player only, no backend and no analytics.
