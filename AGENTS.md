# ChessLab Agent Rules

These rules are durable project guidance for ChessLab work.

- Preserve working chess rules.
- Preserve custom FNAF pieces and theme.
- Do not use paid services without approval.
- Do not expose database secrets in frontend code.
- Use small focused changes.
- Do not rewrite gameplay logic unless required.
- Explain changed files before pushing.
- Commit after successful features.
